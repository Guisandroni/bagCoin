## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues on `Guisandroni/bagCoin`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five canonical triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` at root + `docs/adr/`. See `docs/agents/domain.md`.
